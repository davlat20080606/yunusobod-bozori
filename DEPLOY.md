# 🚀 Бесплатный запуск 24/7 (без компьютера)

Бот и сайт работают в облаке **бесплатно**, даже когда ноутбук выключен:

| Что | Сервис | Зачем |
|-----|--------|-------|
| Сервер (бот + сайт) | [render.com](https://render.com) | Постоянная ссылка `https://yunusobod-bozori.onrender.com` |
| База данных | [neon.tech](https://neon.tech) | Заказы, цены и фото не пропадают при перезапуске |
| «Будильник» | [cron-job.org](https://cron-job.org) | Каждые 10 минут будит сервер, чтобы он не засыпал |

Банковская карта не нужна.

> ⚠️ **Токены, ключи и пароли — только в `backend/.env` и в Environment на Render, никогда в коде.**
> Репозиторий открытый, а Git хранит всю историю: однажды закоммиченный секрет виден всем навсегда.
> Образец со всеми именами — `backend/.env.example` (скопируйте его в `backend/.env`). `.env` в `.gitignore`,
> а тест `backend/tests/test_no_secrets.py` (запускается и на GitHub) падает, если секрет попал в код.
> Если секрет всё же утёк — **меняйте его** (токен бота: `/revoke` в @BotFather), удаления из кода мало.

## 1. База данных (Neon)

1. Зарегистрируйтесь на **neon.tech** (через GitHub или Google).
2. Создайте проект: имя `yunusobod-bozori`, регион **Europe (Frankfurt)**.
3. Скопируйте **Connection string**. Он выглядит так: `postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

## 2. Сервер (Render)

1. Зарегистрируйтесь на **render.com** через GitHub.
2. **New + → Blueprint** → выберите репозиторий `yunusobod-bozori`. Render прочитает `render.yaml`.
3. Заполните переменные:
   * `TELEGRAM_BOT_TOKEN`: токен от @BotFather
   * `DATABASE_URL`: строка из Neon
   * `ADMIN_PIN`: PIN-код базаркома (6 цифр, никому не показывать). Аравачи, таксисты, паттачи и продавцы регистрируются сами, базарком одобряет их в своём кабинете.
   * `AUTH_SECRET`: длинная случайная строка, которой подписываются входы в кабинеты. Получить: `python3 -c "import secrets; print(secrets.token_hex(32))"`. Если поменять — всем придётся войти заново по PIN.
4. Нажмите **Apply**. Сборка займёт около 5 минут.

Ссылку на сайт (`WEBAPP_URL`) указывать не нужно: сервер сам берёт свой адрес Render, сам подключает бота (webhook) и обновляет кнопку «🛒 Bozor» в Telegram.

Проверка: откройте `https://<ваш-адрес>.onrender.com/api/health`, должно появиться `"status":"ok"`.

## 3. Будильник (cron-job.org)

Бесплатный сервер Render засыпает через 15 минут без посетителей.

1. Зарегистрируйтесь на **cron-job.org**.
2. **Create cronjob** → URL: `https://<ваш-адрес>.onrender.com/api/health` → **Every 10 minutes** → Save.

Даже если сервер всё-таки уснёт, бот сам разбудит его при первом сообщении (ответ придёт через 30–60 секунд).

---

## Обновление

Любой `git push` в ветку `main` → Render сам пересобирает и перезапускает сервер.

## Локальный запуск на Mac (для разработки)

```bash
bash start_online.sh
```

Если бот уже работает в облаке, локальная копия **не перехватывает** Telegram: сайт откроется, а бот продолжит отвечать из облака.
